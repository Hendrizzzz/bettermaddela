# Maddela Barangay Officials — Evidence File (2026-08)

- **Task:** identify the punong barangay (barangay captain) of each of Maddela's 32 barangays, plus kagawad where available, with sources and confidence levels.
- **Retrieval date for all web content cited below:** 2026-08-26.
- **Method:** web-content fetching only (Brave Search, Bing Web/News, direct fetches). No git commands run; no production data written. This file is the only file created.
- **Headline finding:** the current (2023-elected) punong barangay could **not** be verified for 31 of 32 barangays from any reachable source. One name exists, single-source and unofficial (Diduyon). Two historical (2010) names were recovered from an official DILG Region 2 PDF. Kagawad rosters: zero evidence found anywhere reachable.

## 1. Term-context finding (read first)

The task brief assumed the next barangay election was "~2025-10". Reachable sources say otherwise:

- Barangay Directory (barangaydirectory.com), snippets retrieved 2026-08-26, states: *"The next Barangay and Sangguniang Kabataan Elections are scheduled for Monday, November 2, 2026"* and, elsewhere on the same site, *"per COMELEC Resolution No. 11191"* and *"Under Republic Act 12232, officials elected will serve a four-year term."*
  - Source URL: https://barangaydirectory.com/home/cagayan-valley/quirino/maddela/barangay-diduyon (site returned HTTP 503 on direct fetch on 2026-08-26; text recovered via Brave Search snippets)
  - Publisher: barangaydirectory.com — **unofficial, non-government community/commercial site**. COMELEC Resolution No. 11191 and RA 12232 could not be fetched directly in this session.
  - Weakness/conflict note: unofficial secondary source; the resolution numbers were not independently verified against comelec.gov.ph or the Official Gazette during this session. However, prior BetterMaddela research (research/2026-08-officials-roster.md, retrieved 2026-08) independently observed that the COMELEC website carries both "2025 Barangay and SK Elections" and "2026 Barangay and SK Elections" navigation sections, which is consistent with a postponed BSKE now scheduled for 2026.
- Practical implication: officials elected at the October 30, 2023 BSKE appear to remain in office through 2026 pending the November 2, 2026 BSKE. **Any captain name published by BetterMaddela must state the term basis and this extension explicitly.**
